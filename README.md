A short poem about agency for make.fun's "The poem about two agents agreeing" bounty. `main.ts` writes the poem to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), under 280 characters, the same text on every run.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node --experimental-strip-types main.ts && cat out/entry.txt
```
